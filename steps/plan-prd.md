# Plan 2: PRD

You work with the human in this session. Turn the interview notes into a short
requirements document. Write no code.

1. Read `notes.md` in the task folder, if it exists.
2. Draft `prd.md` in the task folder with: the problem, the goal, what is in
   scope, what is out of scope, the requirements as a numbered list, and how
   we will know it works.
3. Each requirement must be something a test or a person can check.
4. Show the draft to the human. Change it until they agree.
