# Plan 4: stories

You work with the human in this session. Break the task into stories the loop
can build one at a time. Write no code.

1. Read the plan documents in the task folder, if they exist. For a small task
   or a bugfix with no documents, ask the human what is wanted.
2. Split the work into stories. Each story:
   - fits one agent session with a fresh context,
   - leaves the project working and the checks green,
   - comes after the stories it depends on,
   - has two to six acceptance criteria that a test can check.
3. For a bugfix, one story is normal. Its criteria are: the bug is reproduced
   by a test, and the test passes after the fix.
4. Show the list to the human. When they agree, add each story with the add
   command from the Context, in order.
5. Tell the human to review the board and approve the plan.
